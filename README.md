# EnglishUp — 영어 단어 학습 앱

브라우저에서 바로 실행되는 순수 HTML/CSS/JavaScript 기반 영어 단어 학습 앱입니다. 별도의 설치나 빌드 과정 없이 정적 파일 서버만으로 동작합니다.

## 주요 기능

- **홈 대시보드**: 전체 단어 수, 학습 완료 수, 오늘 학습한 단어 수, 연속 학습일(스트릭), 레벨별 진도를 한눈에 확인
- **플래시카드**: 카드를 클릭해 뜻과 예문을 확인하고, "알고 있어요 / 아직 몰라요"로 학습 상태를 기록. 레벨(초급/중급/고급) 필터와 "아직 모르는 단어만 보기" 옵션 제공
- **퀴즈**: 레벨과 문제 수를 선택해 4지선다 객관식 퀴즈를 풀고 점수를 확인. "뜻 맞추기"(단어 → 뜻)와 "문장 완성"(예문의 빈칸에 들어갈 단어 맞히기, 한글 해석 힌트 제공) 두 가지 유형 지원
- **단어장**: 전체 단어를 검색하고 레벨별로 필터링하며, 학습 완료 여부를 직접 토글

학습 데이터(학습 완료 단어, 오늘 학습량, 연속 학습일)는 브라우저의 `localStorage`에 저장되어 새로고침 후에도 유지됩니다.

## 실행 방법

별도의 의존성이 없습니다. 프로젝트 폴더에서 정적 파일 서버를 실행한 뒤 브라우저로 열면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html` 파일을 브라우저에서 직접 열어도 동작합니다.

## 프로젝트 구조

```
index.html        메인 페이지 (홈 / 플래시카드 / 퀴즈 / 단어장 뷰)
css/style.css      스타일시트
js/app.js          앱 로직 (상태 관리, 뷰 전환, 학습 진도 저장)
data/words.js       단어 데이터 (초급/중급/고급 90개 단어)
```

## 단어 데이터 추가하기

`data/words.js`의 `WORD_DATA` 배열에 아래 형식으로 항목을 추가하면 앱 전체(플래시카드, 퀴즈, 단어장)에 자동으로 반영됩니다.

```js
{ word: "example", pos: "명사", meaning: "예시", example: "This is an example.", exampleKo: "이것은 예시이다.", level: "beginner" }
```

`level`은 `beginner`, `intermediate`, `advanced` 중 하나를 사용합니다.

> "문장 완성" 퀴즈는 `example` 문장에서 `word` 값과 정확히 일치하는 단어(대소문자 무관, 단어 경계 기준)를 찾아 빈칸으로 치환합니다. `runs`, `achieved`처럼 활용형만 들어있으면 빈칸으로 치환되지 않으니, 예문에는 단어 원형이 그대로 포함되도록 작성하세요.
